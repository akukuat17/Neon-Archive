Tentang NEON ARCHIVE

Tujuan Sistem

NEON ARCHIVE adalah arsip terkurasi 33 entri game yang dibangun atas satu prinsip: akses universal tanpa kompromi. Tidak ada batasan hardware, tidak ada kebisingan iklan, tidak ada algorithmic feed. Hanya data bersih - judul, genre, platform, rating, deskripsi teknis - yang bisa Anda cari, filter, dan simpan dalam hitungan detik.

Setiap entri diverifikasi manual. Deskripsi ditulis ulang untuk objektivitas, bukan pemasaran. Rating mengacu pada konsensus kritis dan komunitas, bukan skor toko tunggal.

Arsitektur Teknis

  • Zero-dependency: HTML5, CSS3 (custom properties), ES5+ JS murni. Tidak ada framework, bundler, atau build step.
  • Data-driven: 33 entri game di js/data.js - tambah game baru hanya edit file ini.
  • State lokal: Favorit & riwayat di localStorage (kunci: fav, recent). Tema di localStorage (kunci: tema).
  • Routing statis: detail.html?id=, katalog.html?genre=. Navigasi full-page, tidak ada SPA router.
  • Performa: Gambar JPG dari SteamGridDB + SVG fallback. Native lazy-loading (loading=lazy). Skeleton loading saat render batch.
  • Aksesibilitas: Semantik HTML5, fokus visible, ARIA labels, kontras WCAG AA, reduced-motion support, keyboard shortcuts (/ cari, Esc tutup).
  • Modular JS: data.js (data), tema.js (theme/fav/kartu), katalog.js (search/filter/sort), detail.js (detail page), form.js (validasi).

Desain & Estetika

  • Tipografi: Space Grotesk (display, teknis, futuristik) + Inter (body, readable) + JetBrains Mono (data, kode).
  • Palet Cyberpunk 2077: Dark #060047 / #B3005E / #E90064 / #FF5F9E + Cyan #00F3FF / Emas #FFD700. Light mode: Arasaka Corporate #FDF0F8 base.
  • Elemen tanda tangan: Scanline ambient animation (CSS-only, 8s loop, prefers-reduced-motion respected).
  • Interaksi: Micro-feedback 100-380ms, cubic-bezier(0.16,1,0.3,1). Hover = elevasi + glow. Click = SFX sintetis.
  • Komponen: Card grid responsive, genre chips filter, rating bintang 5, platform icons 16px, trailer embed 720px max-width.

Sumber Data & Aset

  • Metadata game (judul, developer, tahun rilis, platform, link resmi): halaman resmi masing-masing game & Steam Store API.
  • Rating: Agregasi Metacritic, OpenCritic, Steam Reviews, komunitas Reddit/ResetEra. Skala 0-5 bintang (1 desimal).
  • Poster & Screenshot (33 poster + 99 screenshot): Diunduh dari SteamGridDB (CC0/personal use). Format JPG: poster 600x900, screenshot 1920x620. Fallback SVG vektorial jika belum tersedia.
  • Trailer: YouTube embed via youtube-nocookie.com (privacy-enhanced). URL di trailerUrl pada js/data.js.
  • Tipografi: Space Grotesk, Inter, JetBrains Mono via Google Fonts (SIL Open Font License).
  • Audio klik: Sintesis Web Audio API (oscillator + envelope), file media/audio/klik.wav placeholder.
  • Ikon UI: SVG inline (materi desain sistem), tidak pakai font ikon eksternal.
  • Palet Warna: Cyberpunk 2077 - #060047 / #B3005E / #E90064 / #FF5F9E + Cyan #00F3FF / Emas #FFD700.
