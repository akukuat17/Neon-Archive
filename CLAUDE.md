
# Neon Archive — Game Archive Website

Static HTML/CSS/JS project for a game archive/portfolio site. No build step, no framework.

## Structure
```
/c/Users/Ojan/Documents/sem 5/pemro web/Neon Archive/
├── index.html        # Home page
├── katalog.html      # Game catalog listing
├── detail.html       # Game detail page
├── tentang.html      # About page
├── kontak.html       # Contact page
├── css/
│   └── style.css     # All styles
├── js/               # JavaScript modules
└── img/              # Assets (posters, logos)
```

## Key Commands
- Open `index.html` in browser — no server needed
- Live reload: `npx serve .` (if needed)

## Code Standards
- Vanilla HTML5, CSS3, ES6 modules
- No dependencies
- CSS variables for theming (neon colors)
- Semantic HTML
- Mobile-first responsive

## Conventions
- File naming: kebab-case (`detail.html`, `style.css`)
- CSS classes: BEM-ish (`.game-card__title`)
- JS: ES modules (`type="module"` in HTML)
